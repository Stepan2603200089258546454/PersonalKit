# AgentsDocs

Каталог документов, которые создаёт ИИ-агент: планы, заметки, отчёты, результаты исследований, схемы.

## Правила

- Один документ — один файл Markdown в `kebab-case.md`; вложенные темы — в подкаталогах.
- Каталог не участвует в сборке: код и скрипты здесь не размещаются (скрипты — в `../AgentsTools/`).
- После добавления или переименования документа запускается синхронизация решения:
  `powershell -NoProfile -ExecutionPolicy Bypass -File AgentsTools/Sync-Solution.ps1`.
- Виртуальный путь документа в обозревателе решений повторяет путь от корня рабочей области,
  поэтому вложенные каталоги попадают в решение как вложенные папки.

## Индекс документов

- `README.md` — этот файл.
- `http-client-template.md` — шаблон типизированного HTTP-клиента с горячей перезагрузкой:
  регистрация в DI, формат `appsettings.json`, поведение таймаутов, повторов и предохранителя.
